An attempt to recreate original bukkit structure for classic c0.0.23a_01.

## How to install

You can download latest jar in releases tab and run it same as you do with normal bukkit: `java -jar *jar file name*`.

## How to build

1. Clone repository (you'll need [git](https://git-scm.com/)) by using `git clone https://github.com/oldminecraftcommunity/ClassicBukkit` in command prompt.
2. Move to directory you just cloned (`cd ClassicBukkit`) and run `gradlew build`.
3. Done! The build will appear in build/libs/
